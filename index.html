Datos y copias de seguridad

Los datos de esta versión se guardan en el navegador de este dispositivo.

Exportar / importar

Descarga un archivo JSON para guardar tus productos e inventarios. Si cambias de teléfono o navegador, importa ese archivo para recuperar tus datos.

Atajos de voz aprendidos

Cuando una palabra puede ser varios productos (ej. «cesar») la app te pregunta cuál y lo recuerda. También puedes añadir alias de voz a cada producto al editarlo.

Compartir por WhatsApp

Opcional: número con código de país (ej. 5492610000000). Si lo dejas vacío, WhatsApp te deja elegir el contacto.

Importante para esta versión

El almacenamiento es local: no hay sincronización en la nube, cuentas ni acceso desde varios dispositivos. Para evitar perder información, exporta una copia periódicamente. La siguiente versión puede incorporar base de datos online y acceso protegido.
